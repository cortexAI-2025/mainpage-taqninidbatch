Le flux complet en 7 étapes

Chaque étape génère un batch tracé, un QR code unique et un enregistrement Supabase immuable.

🌿
Harvest Batch HB-CHA-2026-07-15-001

Saisie agronomique complète : variété (registre génétique), parcelle, altitude, coordonnées GPS, poids humide, date récolte, coopérative. Génération automatique du QR Taqnin ID.

☀️
Dry Biomass Batch DBB-KET-2026-07-30-002

Deux méthodes : Séchage classique HACCP (4 CCPs surveillés : T°, humidité, durée, microbiologie) ou Fresh Frozen (-18°C → -80°C) pour extraction live. COA laboratoire obligatoire.

⚙️
Tri Industriel ERB / SB / BB / DB / WB

1 DBB → 5 flux traçables en parallèle. Bilan matière temps réel avec alerte anti-détournement (tolérance ±5%). Chaque flux reçoit son propre batch code et QR.

🌹 Biochar — The Rose of Peace BCH- / CCB-

BB + DB + WB → Pyrolyse (lente, rapide, gazéification, torréfaction) → Biochar certifié EBC/IBI + Crédits carbone Verra VCS / Gold Standard. Valorise 100% des déchets.

🔬
Extraction Batch EXB-TAO-2026-08-01-010

9 méthodes d'extraction : CO₂ supercritique/subcritique, Rosin press, Ice Water Hash, Dry Sieve, Live Rosin, Éthanol froid, Huile d'olive, Distillation vapeur. Rendement et paramètres procédé enregistrés.

⚗️
KETAMIX Batch KMX-MA-2026-08-15-001

Assemblage et standardisation des cannabinoïdes. 4 formules : CBD Dom · Balance · CBG Rich · API Grade (GMP EU). Base de tous les produits finis KETAMIX / Chanvre du Maroc.

💊
Produits Finis API / CAP / OIL / SUP / TCT / TOP

6 formes galéniques : API Pharma, Gélules, Huile CBD, Suppositoires, Teintures, Topiques. Conformité EU Novel Food 2015/2283 et GMP EU selon destination.

✈️
Export Batch EXP-MA-2026-09-01-001

Constitution du dossier export : certificat d'origine, phytosanitaire, dossier GMP EU, notification INCB si THC dominant. Lot scellé et prêt à l'expédition internationale.

Génétique & Réglementation

3 corridors THC

Le registre génétique intègre 8 variétés cataloguées avec leurs profils cannabinoïdes, zones de culture, restrictions export et formules KETAMIX recommandées.

≤ 0.3% THC Corridor EU Standard

3 variétés cataloguées — Conforme EU Novel Food

  • Beldiya CBD (8–22% CBD)
  • Sativa locale CBD (5–18% CBD)
  • CBG Rich (8–20% CBG)
  • Export UE sans restriction principale
  • Novel Food 2015/2283 applicable
0.3–1% THC Corridor Maroc / Suisse

3 variétés — Loi 13-21 — Export conditionnel

  • Beldiya (Corridor 1%) — cultivar ancestral Rif
  • Ketama Gold (Khardala) — 1400–2400 m
  • Hybrid CBD/THC équilibré
  • Autorisé Maroc + Suisse ≤1%
  • Export EU : vérification pays destination
THC Dominant Médical / Recherche

2 variétés — Autorisation ANRAC spéciale requise

  • Beldiya THC Dominant (5–25% THC)
  • Beldiya Medical Grade (10–20% THC)
  • GMP EU Annexe 2 obligatoire
  • Quota INCB + ANRAC requis
  • Export DE, FR, UK, Canada uniquement

Traçabilité & Authenticité

QR Code Taqnin ID

Chaque batch génère automatiquement un QR code unique, imprimable et vérifiable publiquement sans connexion.

  • Format TAQ-MA-ZONE-YYYY-TYPE-XXXXXX — identifiant national unique
  • Page publique /verify/:batchCode — accessible sans authentification
  • QR téléchargeable en PNG haute résolution (400px)
  • Impression étiquette directe depuis le navigateur
  • Données encodées : variété, corridor THC, poids, statut, date validation
  • Seuls les batchs validés sont accessibles publiquement

Base de données
6 migrations SQL chronologiques. Tables : batch_nodes, operators, parcels, anrac_alerts, anrac_quotas, anrac_declarations. Vues matérialisées pour le dashboard ANRAC.
Sécurité
Row Level Security (RLS) Supabase par rôle. Seule la route /verify est publique. Chaque rôle ne voit que ses propres données via policies PostgreSQL.
Codification
16 types de batch avec préfixe standardisé. Codes : TYPE-ZONE-YYYY-MM-DD-SEQ. QR global : TAQ-MA-ZONE-YYYY-TYPE-XXXXXX. Zones : CHA, KET, TAO, ALH, FES, TAZ…
